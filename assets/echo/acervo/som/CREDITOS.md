# Sons da bateria do Acervo

Gravações reais de percussão da **Versilian Community Sample Library (VCSL)**, de Sam Gossner,
publicadas em domínio público sob **CC0 1.0 Universal**: https://github.com/sgossner/VCSL

Cada arquivo foi recortado no ataque, convertido para mono, normalizado a -1 dBFS e codificado em MP3 (80 kbps).
A afinação de cada naipe é feita no navegador (`playbackRate`), sobre a mesma gravação.

Não há gravação de cuíca, tamborim, surdo ou repique em acervos CC0 acessíveis daqui; esses naipes usam o
instrumento real mais próximo (bumbo sinfônico afinado para surdo, tom com baqueta para repique, bongô agudo
para tamborim, fricção na pele do bumbo para a cuíca). Gravações próprias com os mesmos nomes de arquivo
substituem estas sem mudar o código.
